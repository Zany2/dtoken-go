# SSO 发布验收清单

[English](RELEASE_CHECKLIST.md) · [测试细则](TESTING_zh.md) · [部署说明](DEPLOYMENT_zh.md)

本清单汇总 SSO 实现和配套示例的验收入口。回归源码已补充并进行静态复核，本轮**未执行**构建、测试、竞态检测、Redis、浏览器及代理联调。静态检查不能视为运行验证通过。

## 待执行的自动化检查

准备工作区要求的 Go 版本和依赖，在仓库根目录执行：

```powershell
go test ./sso/... -count=1
go test ./examples/sso_server/... ./examples/sso_client/... ./examples/sso_gin_server/... ./examples/sso_gin_client/... ./examples/sso_deployment/... -count=1
go test -race ./sso/... ./sso/storage/redis/... ./examples/sso_server/... ./examples/sso_client/... ./examples/sso_gin_server/... ./examples/sso_gin_client/... ./examples/sso_deployment/... -count=1
go test ./sso/storage/redis/... -count=1
```

Redis 模块的集成测试要求 `DTOKEN_REDIS_URL` 指向专用测试 Redis，支持 GETDEL（6.2+）。未设置该变量时集成测试会跳过，构造器检查不能代替真实 Redis 验证。竞态检测需要受支持的 Go race 工具链。部署退出测试会临时监听回环端口。完整命令及存储行为见[测试细则](TESTING_zh.md)。

## 待执行的部署验收

已补充[部署验收入口及故障恢复矩阵](../examples/sso_deployment/ACCEPTANCE_zh.md)：显式启用的真实 HTTP 用例覆盖双应用登录与退出，浏览器／副本／Redis 故障仍需分别验收。当前仅有源码和静态检查，全部运行结果待确认。

| 场景 | 需要记录的验收结果 |
| --- | --- |
| 浏览器与 HTTPS 代理 | Alpha／Beta 登录、多标签页、Secure／SameSite Cookie、伪造 Origin 拒绝、公开来源和跳转地址保持正确 |
| Redis 多副本 | 登录发起和回调落在不同副本；重启后会话连续；已消费回调无法再次使用 |
| 本地／全局注销 | 本地退出不影响其他应用；全局退出清理参与应用的账号会话；其他账号不受影响 |
| 通知失败 | 停掉一个应用，观察严格模式失败及部分完成；恢复后用新请求重试 |
| 存储失败 | 就绪检查返回 503；身份和会话检查不悄悄回退内存；恢复后按需重新发起登录 |
| 退出清理 | 分别验证正常排空与在途操作期间强制关闭连接；钩子响应取消后才释放存储 |

45 秒排空期不是进程强制退出期限：关闭连接后仍等待处理器返回。不响应取消的钩子需要单独的进程管理器终止策略。验收完成前，记录环境、提交／工作区版本、命令、结果及跳过项。生产使用前需替换部署示例中的固定账号认证器。
